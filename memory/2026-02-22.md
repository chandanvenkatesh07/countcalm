## CalmCount app context (user asked to remember)
- Project path: `/home/master/.openclaw/workspace/calm-count`
- Stack: Expo + React Native + TypeScript.
- Purpose: calm, low-stimulation early-math app for kids (home subtitle says ages 4–6), designed for simple predictable interactions with supportive feedback.
- Core learning modes: Counting, Addition (Numbers), Addition (Pictures), Subtraction.
- How it works:
  - Home screen with four modes and long-press Parent Zone.
  - Parent Zone settings: skip counting, sound toggle, voice prompts, minimal animations.
  - Question flow uses drag-and-drop number cards (and picture-choice mode for one addition chapter).
  - Audio + voice cues (mp3 instruction clips + expo-speech fallback), haptics, success/confetti feedback.
  - Progress is local-only in AsyncStorage key `calm_count_stats_v1` with games played, first-try wins, per-level and daily stats.
  - Adaptive progression and regression logic (advance levels on success; step back after repeated first-try failures).
- Assets include themed 3D objects (apple/star/ball/block/banana) and instruction/success/retry audio clips.
- Build/run scripts: `npm run start`, `npm run ios`, `npm run android`, `npm run web`.
