# Research Roles (Deep Research Standard)

Use one-word triggers in chat:
- `Topic: stock`
- `Topic: legal`
- `Topic: market`

Every role in this folder is now tuned for **deep research by default** and produces:
1) specialist-grade analysis
2) a leadership-friendly summary (plain language, decision-focused)

## Universal Deep-Research Contract (applies to every role)

### A) Research Sequence
1. **Frame the Decision**
   - Clarify decision owner, decision to make, timeline, constraints, and success criteria.
2. **Define Key Questions**
   - Convert request into answerable questions and hypotheses.
3. **Source Plan**
   - Prioritize primary sources, then high-quality secondary sources.
4. **Evidence Collection**
   - Gather latest data + historical context; preserve links and dates.
5. **Validation**
   - Cross-check critical claims with 2+ credible sources when possible.
6. **Analysis & Synthesis**
   - Quantify tradeoffs, identify drivers, risks, and scenarios.
7. **Recommendation Package**
   - Specialist analysis + leadership summary + visuals + optional PPT outline.

### B) Data Quality Rules
- Label data as: **Verified / Estimated / Assumed**.
- Report data recency and known gaps.
- Separate **facts, interpretation, and opinion**.
- Include counterevidence and why it does/does not change conclusion.

### C) Output Layers (always)
1. **Leadership Summary (1 page style)**
   - What matters, what changed, what to do next.
2. **Specialist Analysis**
   - Detailed methods, evidence tables, and technical detail.
3. **Action Plan**
   - 30/60/90-day options, owners, dependencies, risks.

### D) Visuals Standard
Default visual package when data supports it:
- Trend chart (time series)
- Comparison chart (peer/option benchmark)
- Scenario table (best/base/worst)
- Risk heatmap (impact x likelihood)
- Driver tree or logic map (if quantitative data is limited)

### E) PPT-Ready Standard
If `Deliverable: deck`, produce 10-14 slides:
- Slide title
- Core message (one sentence)
- Suggested chart/table
- 2-4 bullets max
- Speaker note (what leadership should conclude)
- Final appendix: sources, assumptions, definitions
