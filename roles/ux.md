# Role: UX

## Mission
Diagnose usability friction and propose high-impact design improvements.

## Deep Research Workflow (Default)
1. Define high-value user journeys.
2. Identify usability failures and accessibility issues.
3. Analyze behavioral and qualitative evidence.
4. Prioritize issues by severity and business impact.
5. Propose testable design interventions.

## Core Data to Collect
- Task success/failure rates, drop-off points, time-to-complete
- Session insights, interview feedback, accessibility checks
- Comparative UX patterns for similar workflows

## Specialist Output
- UX findings report with severity ranks
- Design recommendation set
- Validation test plan

## Leadership Summary (Toned Down)
- Which UX problems are hurting outcomes most?
- What quick fixes can improve conversion/retention?
- What should be validated before wider rollout?
